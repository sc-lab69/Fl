ทำความเข้าใจโปรแกรม Scratch 3.0

Scratch พัฒนาโดยสถาบัน MIT เพื่อให้ทุกคนเรียนรู้การเขียนโค้ดได้ง่ายๆ ผ่านการต่อบล็อกคำสั่งที่มีสีสันชัดเจน มาดูส่วนประกอบของหน้าจอและบล็อกคำสั่งสำคัญกันครับ

🖥️ 4 ส่วนประกอบหลักของหน้าต่าง Scratch 3.0

🎨

1. เวที (Stage)

พื้นที่แสดงผลลัพธ์ของเกม มีพิกัดแกน X (-240 ถึง 240) และแกน Y (-180 ถึง 180) เป็นจุดที่ถังขยะและขยะจะปรากฏ

🐱

2. รายการตัวละคร (Sprites)

รายชื่อตัวละครทั้งหมดในเกม เช่น ถังขยะ 4 สี, ตัวละครขยะชนิดต่างๆ รวมถึงภาพพื้นหลังโรงเรียน (Backdrop)

🧩

3. แถบบล็อกคำสั่ง (Palette)

คลังรวมบล็อกคำสั่ง แบ่งออกเป็นหมวดสีต่างๆ เช่น สีเหลือง (Events), สีส้ม (Control), สีฟ้า (Sensing)

📐

4. พื้นที่เขียนสคริปต์ (Scripts)

พื้นที่สำหรับลากบล็อกคำสั่งมาต่อเรียงกันเป็นลำดับอัลกอริทึม เพื่อสั่งให้ตัวละครทำงานตามที่เราต้องการ

สำรวจบล็อกคำสั่งที่ต้องใช้ในเกมคัดแยกขยะ

คลิกเลือกหมวดหมู่เพื่อดูบล็อกและวิธีนำไปใช้งาน

เมื่อคลิก ⚑
หมวด Events (สีเหลือง)

บล็อกเริ่มต้นทุกโปรแกรม เมื่อผู้เล่นกดปุ่มธงเขียวเพื่อเริ่มเล่นเกม จะใช้สำหรับตั้งค่าคะแนนเป็น 0 และเริ่มนับเวลาถอยหลัง

วนซ้ำตลอด (forever)
// รหัสคำสั่งทำงานไม่หยุด
หมวด Control (สีส้มทอง)

สั่งให้ตัวละครตรวจสอบการสัมผัสหรือการเคลื่อนไหวซ้ำๆ ตลอดทั้งเกม เพื่อให้เกมตอบสนองต่อผู้เล่นแบบเรียลไทม์

แตะ ถังขยะสีเขียว หรือไม่?
หมวด Sensing (สีฟ้าอ่อน)

เปลี่ยน คะแนน ทีละ 10
หมวด Variables (สีส้มเข้ม)

เพิ่มค่าของตัวแปรคะแนน (Score) ขึ้น 10 แต้มเมื่อผู้เล่นทิ้งขยะได้ถูกต้องตรงกับถังขยะที่กำหนด

สร้างร่างโคลนของ ตัวเอง (myself)
หมวด Control (สีส้มทอง)

คำสั่งเสกขยะชิ้นใหม่ให้ตกลงมาเรื่อยๆ โดยไม่ต้องวาดตัวละครซ้ำ ช่วยให้เกมมีขยะไหลลงมาได้ไม่จำกัด!

ใช้สุ่มพิกัดแกน X เพื่อให้ขยะแต่ละชิ้นตกลงมาจากตำแหน่งต่างๆ บนท้องฟ้า ทำให้เกมน่าตื่นเต้นและไม่ซ้ำเดิม

สร้างระบบตัวแปร (Variables: คะแนน และ เวลา)

ในเกมที่มีการแข่งขัน เราจำเป็นต้องมี ตัวแปร (Variables) เพื่อเก็บข้อมูลระหว่างเล่นเกม:

  • คะแนน (Score) : เริ่มต้นที่ 0 เพิ่มขึ้นเมื่อคัดแยกถูก
  • เวลา (Timer) : เริ่มต้นที่ 60 วินาที และนับถอยหลังทีละ 1

คลิกที่หมวดสีส้ม Variables ➔ Make a Variable ติ๊กเลือก For all sprites แล้วสร้างตัวแปรทั้งสองตัว
